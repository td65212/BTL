Làm thế nào để implement Dependency Injection trong ASP.NET Core?

Mình đang học ASP.NET Core và gặp khó khăn với Dependency Injection. Ai có thể giải thích cách implement nó với ví dụ cụ thể không? Mình đã thử theo tài liệu Microsoft nhưng vẫn chưa hiểu rõ cách áp dụng vào dự án thực tế.

Cụ thể mình muốn hỏi về:

  • Cách đăng ký service
  • Cách inject vào controller
  • Lifecycle của DI trong ASP.NET Core

Trong ASP.NET Core, Dependency Injection (DI) được tích hợp sẵn. Dưới đây là cách triển khai cơ bản:

  1. Đăng ký service trong Program.cs hoặc Startup.cs:
builder.Services.AddScoped<IMyService, MyService>();

Có 3 loại lifecycle:

  • AddTransient: Tạo mới mỗi lần request
  • AddScoped: Tạo mới mỗi scope (thường là mỗi request)
  • AddSingleton: Chỉ tạo một instance duy nhất

Bạn có thể inject service vào controller qua constructor:

public class MyController : Controller
{
    private readonly IMyService _myService;
    
    public MyController(IMyService myService)
    {
        _myService = myService;
    }
    
    public IActionResult Index()
    {
        var data = _myService.GetData();
        return View(data);
    }
}
